# 🛒 Bazar-Dor — বাজার দর

A responsive web application for exploring market prices of everyday products in Bangladesh.

## 🌐 Live Website

[Visit Bazar-Dor](https://b14-a7-bazar-7jhid23o3-a7-e8ea.vercel.app/)

## ✨ Features

* Responsive design for desktop, tablet, and mobile devices
* Product price browsing
* Product search and filtering
* Rising and falling price highlights
* Bengali date and number formatting
* Product categories and market price information

## 🛠️ Technologies Used

* Next.js
* React
* TypeScript
* CSS
* REST API

## 🚀 Getting Started

### Prerequisites

* Node.js
* npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ashrafulislam1122/B14-A7-Bazar-Dor.git
   ```

2. Navigate to the project directory:

   ```bash
   cd B14-A7-Bazar-Dor/temp-bazar-check
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open http://localhost:3000 in your browser.

## 📡 API

The application uses an API to retrieve market and product information.

* Primary API: `https://api.api-store.workers.dev/api/bazardor`
* Fallback API: `https://api.abcz.workers.dev/api/bazardor`
